# LatinRengo

- Proyecto Astro independiente. Leer README.md y docs/migracion.md antes de editar.
- Para ubicar flujos y límites actuales, usar docs/README.md y docs/ia-first.md; contrastar cada afirmación con src/.
- Trabajar en este repositorio; no modificar el sitio de Espacio Elementos por arrastre.
- Mantener exclusivamente identidad, contenido y recursos de LatinRengo.
- Conservar las referencias reales a Espacio Elementos como recinto o colaborador.
- La fuente de verdad es src/. No editar dist/ ni compartir node_modules con otros repositorios.
- Mantener PUBLIC_SITE_URL como origen único de metadatos y sitemap.
- No inventar dominio, fechas, precios, artistas ni disponibilidad de entradas.
- No publicar contenido withheld ni copiar datos bancarios o personales en documentación.
- Preservar consentimiento de Analytics y funcionalidad de menú, afiches y QR.
- Tras cambios ejecutar npm run build y revisar enlaces, assets y responsive si corresponde.
- No hacer commit, push ni deploy sin solicitud explícita.
